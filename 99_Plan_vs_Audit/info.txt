1. Ghid Google Maps Places API — Pas cu Pas

  ▎ Atenție: Google Maps Places API necesită activarea billing (card de credit) chiar dacă oferi $200 credit gratuit/lună. Din        
  perspectiva politicii free-only, aceasta este o sursă condiționată — funcționează gratuit în limitele creditului, dar necesită card.
  Dacă vrei totuși să îl obții:

  Pasul 1 — Creează/accesează Google Cloud Console:
  https://console.cloud.google.com/

  Pasul 2 — Creează un proiect nou:
  - Click Select a project → New Project → Denumire: RIS-Backend

  Pasul 3 — Activează Places API:
  https://console.cloud.google.com/apis/library/places-backend.googleapis.com
  → Click Enable

  Pasul 4 — Creează API Key:
  https://console.cloud.google.com/apis/credentials
  → Create Credentials → API Key
  → Restricționează la: Places API + IP-ul serverului tău

  Pasul 5 — Activează billing (obligatoriu):
  https://console.cloud.google.com/billing
  → Adaugă card → primești $200 credit/lună (~28.500 requests Places gratis)

  Pasul 6 — Adaugă în .env:
  GOOGLE_CLOUD_API_KEY=AIza...

1. Ce să alegi — IP addresses

  Aplicația RIS face apeluri server-side (Python backend), nu din browser. Deci:

  Alege: IP addresses (nu Websites — aia e pentru aplicații web/browser)

  Apoi vei adăuga:
  - 127.0.0.1 — localhost (pentru development)
  - IP-ul Tailscale al PC-ului tău (găsești în aplicația Tailscale → 100.x.x.x)

  Și separat, după ce confirmi IP-ul, vei vedea secțiunea API restrictions → selectează Places API only.
